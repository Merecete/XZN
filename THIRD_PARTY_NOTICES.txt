XZN - Third-party software

The ready-to-use XZN packages (Windows installer, macOS app, Linux .deb,
AppImage and archive) also contain the following open-source components.
Each one stays under its own license. The full license texts are in the
"licenses" folder next to the program; the exact versions included in a
package are listed in licenses/VERSIONS.txt. The source code of every
component is publicly available at the addresses below.

x264 / x265 encoders inside FFmpeg), the XZN packages as a whole are
distributed under the terms of the GNU GPL version 3 (or later); XZN's own
code remains available under the BSD 3-Clause License. The complete
source code of XZN is available at https://github.com/Merecete/XZN; the
source of each component is available from the addresses listed here, and
on request from the XZN author for at least three years after a release.

The LGPL libraries (FFmpeg, libsndfile, ...) are included as separate
shared libraries (.dll / .so / .dylib) in the program folder and can be
replaced with compatible versions.

Patent note: some codecs (e.g. H.264/H.265 video) may be covered by
patents in some countries. XZN only uses them to play media files.
